This project is for me to test and learn how Spring Boot REST API development works. MySQL is used as the database and Postman is used for testing API calls.

Things done in this project so far:
  - implemented CRUD-operations
  - implemented secure JWT authentication and role-based authorization.
    
Currently working on:
  -Frontend for making API calls. Using TypeScript and Angular.
